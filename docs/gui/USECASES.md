# ユースケースと、人が確かめること（GUI）

リリースの前に行う確認です。2 つに分けています。

1. **ユースケースのテスト（自動）**: GUI を人と同じ順に操作し、ファイルの状態・画面・保存した結果までを通しで確かめる。`python -m pytest test_usecases.py`（数秒）
2. **人が確かめること（手で行う）**: 本物の exe・エクスプローラー・Excel を使うことや、見た目のように、自動では確かめられないもの

単体テスト（`test_migrate_files.py`・`test_gui.py`）と CLI のシナリオ（`testdata/SCENARIOS.md`）は部品ごとの確認で、このページはその上の「使い方ごと」の確認です。

---

## 1. ユースケースのテスト（自動・`test_usecases.py`）

すべて ①対象フォルダ → ②保存先フォルダ → ③④設定 → 確認 → 実行 の順に操作します。

| # | 使い方 | 操作 | 確かめること |
|---|---|---|---|
| UC1 | ダウンロードの整理（既定の設定） | Downloads（サブフォルダ・`(1)` 付きの重複・desktop.ini などを含む）→ デスクトップ\整理 | 確認では何も変えない。実行で構成と中身をそのまま移し、重複と空のフォルダを消し、desktop.ini・Office の一時ファイル・ダウンロード途中のファイルは残る。「完了: 6 件を移動しました」、一覧は閉じて CSV・ログを保存、対象フォルダの一覧から外れる |
| UC2 | コピーでバックアップ | 写真 → USB\写真のバックアップ（コピー） | 元は変わらず、同じ中身ができる。確かめの画面は出ない。もう一度確認すると「コピーするファイルはありません」で全件「処理済み」 |
| UC3 | 保存先に同じ名前のファイルがある | 同名の別の中身・同じ中身があるところへ移動。同名ファイルの処理を 連番 → スキップ → 上書き と変える | 連番: `メモ_1.txt` で両方残り、同じ中身は元だけ消す。スキップ: 元は残り、黄色の見出しと「⚠ スキップしました」。上書き: 新しいものになる |
| UC3b | 全部がスキップになる | 同名の別ファイルしかない状態で、スキップを選んで確認 → 連番に変えて確認 → 実行 | 確認の見出しが「1 件は保存先に同名の別ファイルがあるためスキップします」（黄色）で、実行は押せない。連番に変えると移せる |
| UC4 | PDF だけを移す | ファイルの種類に `pdf` | `.pdf`・`.PDF` だけ移り、ほかは残る。対象フォルダは一覧に残る |
| UC5 | 最近のファイルだけを移す | 期間に `30d` | 3 日前のものだけ移り、400 日前のものは残る |
| UC6 | 複数のフォルダを 1 か所にまとめる | PC1\書類 と PC2\書類 → まとめ | 同じ名前の `報告書.docx` は `報告書_1.docx` として両方残る |
| UC7 | 確認の後にファイルが増えた・設定を変えた | 確認 → ファイルを足す → 実行。確認 → コピーに変える → 実行 | 確認していないファイルは移さない。設定を変えると「設定が変わりました」で実行できない |
| UC8 | 途中で中止して、後で続きを行う | 20 件の移動を 3 件目あたりで中止 → 確認 → 実行 | 「中止しました」。消えたファイルも二重のファイルも無い。続きの確認は残りの件数だけで、最後に全部そろう |
| UC9 | 開いている（使用中の）ファイルがある | 1 件を開いたまま実行 → 閉じてもう一度 | そのファイルだけ「✗ エラー」で元に残り、書きかけも残らない。閉じた後に移せる（Windows のみ） |
| UC10 | 変わったファイル | 読み取り専用・空白・絵文字・深い階層の長い名前 | どれもそのまま移る |
| UC11 | 入力の誤り | 保存先を対象フォルダと同じにする。追加した対象フォルダを消してから確認。まだ無い保存先 | 何もせず「入力を確かめてください」。無い保存先は作る |
| UC12 | 対象フォルダの中のフォルダに整理する | Downloads → Downloads\整理 を 2 回 | 1 回目で整理に移り、2 回目は「移動するファイルはありません」（整理\整理\… にならない） |

使い方を足したり、画面の振る舞いを変えたりしたら、この表と `test_usecases.py` を一緒に直します。

## 2. 人が確かめること（リリースの前に、手で行う）

実際に使う形（exe・エクスプローラー・Excel）で確かめます。終わったらチェックを付けます。

### exe

- [〇] `dist\FileMove.exe` をデスクトップなど別の場所にコピーして、ダブルクリックで起動できる
- [〇] ウィンドウのタイトルが「FileMove 1.0.0」になっている
- [〇] exe を右クリック →「プロパティ」→「詳細」で、製品名 FileMove・バージョン 1.0.0 が出る
  >ファイルの説明はFileMoveいる？
- [〇] 「デジタル署名」タブに「FileMove (self-signed)」がある
- [✖] （ほかの PC があれば）ほかの PC で起動すると SmartScreen の警告が出て、「詳細情報」→「実行」で開ける
  >ほかのPCはない

### 本物のフォルダで

- [〇] 本物のダウンロードフォルダを**コピーしたもの**で、確認 → 実行（移動）まで行い、エクスプローラーで中身を見て、移ったもの・残ったものが一覧のとおり
- [〇] エクスプローラーからのドラッグ＆ドロップで、対象フォルダ・保存先フォルダを入れられる（exe を何度か起動し直しても毎回使える）
- [✖] USB メモリなど別のドライブへの移動ができる（コピーしてから元を消すので、同じドライブより時間がかかる）
  >ない
- [✖] （使っていれば）NAS・ネットワークドライブへの移動ができる
  >ない
- [ ] Excel で開いたままのファイルがあるときに、そのファイルだけ赤い「✗ エラー」になり、Excel を閉じてもう一度行うと移せる
　>試してない
- [ ] 大きなファイル（1GB 以上）を移すときに、進捗バーが進み、固まって見えない
　>試してない
- [ ] 実行中に「中止」を押すと止まり、もう一度「確認」から行うと続きから移せる
　>試してない
- [ ] 実行中にウィンドウを閉じようとすると確かめられる
　>試してない
### 結果

- [ ] 終わったときに、終わったこと（緑の見出し）と、残ったもの（黄色・赤の見出しと一覧）がひと目で分かる
>試してない
- [ ] 「結果を開く」で結果の CSV が Excel で開き、文字化けしない
>試してない
- [ ] 「保存先を開く」で保存先がエクスプローラーで開く
>試してない
- [ ] `%LOCALAPPDATA%\FileMove\履歴` に結果の CSV とログが日時の名前で残っている
>試してない

### 見た目

- [✖] 画面の拡大率（設定 → ディスプレイ → 拡大/縮小）が 100%・125%・150% のどれでも、文字が切れたり重なったりしない
　>拡大率の表示が出ない、けど要らないと思う、画面を全画面にしても文字が切れたりしてない。
- [〇] 文言が分かりやすい（分かりにくいものがあれば fix.md に書く）

### このリリースで入った細かい修正

自動のテストは通っていますが、実際の使い方でも問題ないかを確かめます。

- [〇] バージョン番号（CLI の `python migrate_files.py --version`・GUI のタイトル・exe のプロパティ）
