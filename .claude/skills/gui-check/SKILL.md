# GUI の見た目を確かめる

テスト（`python -m pytest test_gui.py`）は動きしか見ない。見た目（はみ出し・重なり・字間・色・空白）は
画面を撮って目で確かめる。

## 手順

1. デモのパターンを、待たずに動かして画面を PNG で撮る（画面にウィンドウが一瞬出る）

   ```
   python demo/gui/demo_gui.py --snap <スクラッチのフォルダ>/snap 1 2 4 5
   ```

   - パターンは `demo/gui/demo_gui.py` の G1〜G6（1: 確認だけ、2: 移動、3: 振り分け、4: 重複削除、5: 同名・コピー、6: ドライブ間）
   - 画面が変わるたびに `g<番号>_<連番>.png` が保存される。最後の 1 枚が終わったときの画面
   - 撮影先はリポジトリの外（スクラッチのフォルダ）にする

2. Read ツールで PNG を開いて見る。少なくとも次の画面を見る
   - 最初の画面（`g1_01.png`）: ①②③ の並び、案内の文言、ドラッグ＆ドロップの案内
   - 確認だけの後（G1 の最後）: 青の「確認だけしました」と、一覧の「→ 移動します」
   - 完了の後（G2 の最後）: 緑の「完了しました」、「移す先を開く」、① から外れたこと
   - 詳細設定を開いた画面（G4・G5）: 項目の並び、はみ出しがないか

3. 見るところ
   - 文字が切れていないか、ボタンの幅が足りているか、字間が崩れていないか（太字の合成は字間が崩れる）
   - 結果の見出しの色: 完了＝緑 / 確認だけ・案内＝青 / 残したもの・中止＝黄 / 失敗＝赤
   - 一覧の行の色: 残した＝黄の背景、失敗＝赤の背景、済み＝灰色、予定＝青
   - 表示上のパスが `C:\Users\user\…` / `D:\…` になっていて、実際の作業フォルダが出ていないか

4. 直したらもう一度撮って確かめる。よければ `python demo/gui/demo_gui.py` で GIF（`docs/images/gui/`）を
   作り直す（録画中は画面にウィンドウが出る。数分かかる）

## 新しい状態を見たいとき

デモに無い状態（失敗した行など）を見たいときは、`demo/gui/demo_gui.py` にパターンを足すのではなく、
スクラッチのフォルダにスクリプトを書いて `App` を動かし、`Recorder(root, "タイトル", realtime=False)` の
`shot()` と `save_png()` で撮る。デモのパターンは、マニュアルに載せる使い方だけにする。
